# FitPac — GitHub Pages

This is a static FitPac website prepared for GitHub Pages.

## Files

- `index.html` — website structure
- `styles.css` — visual styles and responsive layout
- `script.js` — navigation, category rendering, and interactions
- `assets/fitpac-logo.png` — FitPac logo
- `.nojekyll` — tells GitHub Pages to serve the site as-is

## Deploy on GitHub Pages

1. Put these files in the **root** of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**.
6. Wait for GitHub Pages to build the site.

Your address will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Notes

The current page uses Google Fonts and several Unsplash image URLs, so those visual assets are loaded from the internet. The site itself is static and does not require a server or database.
